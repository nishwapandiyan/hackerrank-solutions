# Insight     The implementation calculates the required padding width based on the binary representation of the maximum number and applies right-justification to each formatted string representation.
# Interview   Before: "I would manually calculate the binary length and use string concatenation." After: "I used the built-in rjust method with a pre-calculated width to ensure O(n log n) time complexity, where log n is the number of bits in the maximum integer."
# Pitfalls    (1) Failing to subtract two from the binary string length, which includes the '0b' prefix.  (2) Using incorrect padding width by failing to account for the binary representation of the maximum number.  (3) Forgetting to convert hexadecimal characters to uppercase as required by the problem statement.
# ──────────────────────────────────────────────────

def print_formatted(number):
    width = len(bin(number)) - 2

    for i in range(1, number + 1):
        decimal = str(i)
        octal = oct(i)[2:]
        hexa = hex(i)[2:].upper()
        binary = bin(i)[2:]

        print(
            decimal.rjust(width),
            octal.rjust(width),
            hexa.rjust(width),
            binary.rjust(width)
        )
