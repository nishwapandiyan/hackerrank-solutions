# Insight     The implementation utilizes a hash set to automatically handle duplicate entries while maintaining a collection of unique country names.
# Interview   Before: "I would iterate through the list and check if each item exists in a new list before adding it." After: "Using a set provides O(1) average time complexity for insertions, resulting in an O(N) total time complexity to count N distinct stamps."
# Pitfalls    (1) Assuming the .add() method returns the updated set instead of None, which could lead to errors if the return value is assigned to a variable.  (2) Failing to account for the O(N) space complexity required to store all unique country names in the set.
# ──────────────────────────────────────────────────

n = int(input())
Set = set()
for i in range(0,n):
    name = input()
    Set.add(name)
print(len(Set))
