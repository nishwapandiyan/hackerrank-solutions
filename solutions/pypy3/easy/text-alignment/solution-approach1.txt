# Insight     The logo is constructed by concatenating string-aligned segments of varying widths based on the input thickness parameter.
# Interview   Before: "How do I handle variable spacing in ASCII art?" After: "I use Python's string alignment methods rjust, ljust, and center to maintain consistent padding, resulting in O(thickness^2) time complexity to print the full logo structure."
# Pitfalls    (1) Incorrectly calculating the total width for center alignment leads to misaligned logo segments.  (2) Failing to account for the odd-number constraint on thickness causes visual distortion in the final output.  (3) Using incorrect padding characters instead of the default space character breaks the required logo shape.
# ──────────────────────────────────────────────────

thickness = int(input())
c = 'H'
for i in range(thickness):
    print((c*i).rjust(thickness-1) + c + (c*i).ljust(thickness-1))
for i in range(thickness + 1):
    print((c*thickness).center(thickness*2) + (c*thickness).center(thickness*6))
for i in range((thickness+1)//2):
    print((c*thickness*5).center(thickness*6))       
for i in range(thickness + 1):
    print((c*thickness).center(thickness*2) + (c*thickness).center(thickness*6))   
for i in range(thickness):
    print(((c*(thickness-i-1)).rjust(thickness) + c +(c*(thickness-i-1)).ljust(thickness)).rjust(thickness*6))
